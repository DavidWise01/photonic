The six beam splitters are modeled as lossless 2×2 unitary couplers. An independent per-output attenuation stage follows. RGB and displayed colors label logical source combinations; no simulated wavelength conversion occurs.

Four-bit implicit state registerRGB × RELATIVE PHASE

Mode bits: [phase][B][G][R]. The fourth optical input is a reference, active when an RGB component is on. Phase bit flips the reference by π. State 0 and state 8 are both dark: phase is not measurable without light.

4 × 4 transfer matrix|Uout,in|² & phase

Matrix values arise from multiplying six unitary beam-splitter rotations. Each cell shows the power transfer from one input to one output, and the complex phase. Column sums should equal one (before loss).
